# Ad Performance Analysis Using Excel

## Objective
This folder contains Excel-based analysis of marketing campaigns to identify profitable and non-profitable campaigns.

## Tool Used
- Microsoft Excel

## Metrics Analyzed
- CTR (Click Through Rate)
- CPC (Cost Per Click)
- CPA (Cost Per Acquisition)
- ROAS (Return on Ad Spend)

## Techniques
- Pivot Tables to summarize and compare campaign performance
- IF Logic to categorize campaigns as profitable or non-profitable
- Excel formulas for metric calculations

## Insights
- Segmented campaigns based on ROAS
- Identified campaigns with high CPA or low CTR
- Provided actionable recommendations for budget allocation and campaign optimization
